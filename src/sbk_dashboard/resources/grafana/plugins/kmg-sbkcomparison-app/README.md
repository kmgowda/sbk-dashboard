# SBK/SBM Time Comparison

This plugin is bundled with SBK Dashboard. Open it through the **Compare selected** action in the management UI.
Every selected target initially follows the global live range. A target can then use an independent relative-live
or fixed absolute range without creating another dashboard or changing endpoint identity.
